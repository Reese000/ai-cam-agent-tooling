# AI CAM 3.0 — Skill Index

Skills are organized by the 7-phase development cycle. Load the relevant skill before dispatching agents for that phase.

## Phase Skills

| Skill | Phase | Purpose |
|-------|-------|---------|
| `cam-research` | 1 — Research | Literature mining, competitive analysis, algorithm extraction |
| `cam-documentation` | 2 — Documentation | Module contract writing, API spec generation, schema registry |
| `cam-planning` | 3 — Planning | Task decomposition, dependency graphing, wave allocation |
| `cam-development` | 4 — Development | TDD implementation, multi-agent dispatching, zero-debt enforcement |
| `cam-testing` | 5 — Testing | Test suite orchestration, property-based testing, benchmark verification |
| `cam-audit` | 6 — Auditing | Multi-dimensional audit: code quality, security, performance, architecture |
| `cam-critic` | 7 — Criticism | Bias-free contextless review methodology |

## Infrastructure Skills

| Skill | Purpose |
|-------|---------|
| `cam-architecture-canvas` | Core architectural patterns and constraints |
| `cam-orchestration` | Pipeline orchestration and cron configuration |
| `cam-post-processor` | MDP-based post processor generation and verification |
